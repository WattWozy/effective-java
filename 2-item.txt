=> Use the JavaBeans pattern, as long as you garantee a consistent.

=> Use the BuilderPattern: guarantees that the object is completely built before performing any 
	operations with/on it. This is key.

=> Builder pattern: returns a Builder object that the object's constructor requires for returning 
	a new object. The Builder, is a public inner, static class inside of the Class we want to 
	instantiate. 

=> Builder pattern allows as well for checking the vailidity of the parameters passed to the builder. 
	It also allows for more granular runtime creation errors.
